# GoRogue ゲームデザイン

## 目的と規範

GoRogue は Rogue 5.4.4 のゲーム体験を Go で実装します。ゲームの必須要件、対象範囲、受け入れ条件は [`SPEC.md`](../SPEC.md) を唯一の規範とします。本書はその要件をゲーム体験として要約し、異なるルールセットや未実装機能を追加要件にしません。

## プレイヤー体験

1. プレイヤーは 1 階から 26 階までを探索する。
2. 部屋、通路、暗室、宝物室、迷路階、隠し通路・扉を調べ、モンスターや罠に対処する。
3. 武器、防具、指輪、食料、薬、巻物、杖などの原作アイテムを発見し、使用・識別する。
4. 26 階でイェンダーのアミュレットを得た後、階段を上って地上へ帰還する。
5. HP が尽きると死亡し、そのゲームはパーマデスとなる。

## ルール

- 行動とモンスターの応答は Rogue 5.4.4 のターン制ルールに従う。
- 命中、ダメージ、成長、回復、食料消費、罠、アイテム効果、識別、モンスター能力は原典との一致を要件とする。
- GUI と CLI の操作は共通コマンド実行経路を使う。画面ごとに異なるゲームルールを持たない。
- 乱数はゲーム管理のシード付き乱数源を使う。同じバージョン、シード、入力列で同じ結果を得る。
- セーブは JSON 形式 `1.4.0`。ゲーム状態を復元するためのデータを保存し、旧形式を暗黙に変換しない。

## 表示

ゲーム状態の地形・可視性・探索状態・表示対象を論理表示セルへ変換し、文字レンダラーが記号、色、gruid のグリッドへ変換します。GUI はその文字グリッドを SDL2 で表示します。タイル画像、アニメーション、音声、ネットワーク、マルチプレイは Rogue 5.4.4 のゲーム機能ではないため対象外です。
