# GoRogue - プロジェクト概要

## 概要

GoRogueは、Go言語とgruidライブラリを使用して開発された本格的なローグライクゲームです。伝統的なローグライクゲームの要素を忠実に再現し、手続き生成ダンジョン、ターンベース戦闘、パーマデス（永続的死）、探索重視のゲームプレイを提供します。

**現在の開発状況**：Go言語の特性を活かした高性能で保守性の高いアーキテクチャを実現しつつ、コアゲームシステムの実装を進めています。

## v0.3.0 の実装状況

要件の正は `SPEC.md` です。現在の実装は、26階層のダンジョン、シード付き生成、階段とアミュレットによる勝利条件、基本アイテム、識別、JSON セーブ/ロードを中心に構成されています。GUI と CLI は共通の `DungeonManager` を参照します。

旧版の説明には計画中の機能や現行仕様に含まれない機能が残っています。特にセーブ時の乱数状態復元、全コマンドの GUI/CLI 共通化は未完了です。

## プロジェクトの目的

- **伝統的なローグライクゲーム体験の提供**: オリジナルRogueの26階層構造を再現
- **高品質なソフトウェアアーキテクチャの実現**: 責務分離、テスト可能性、拡張性を重視
- **教育的価値の提供**: ゲーム開発のベストプラクティスを実例として示す
- **継続的な開発・保守の実現**: 段階的リファクタリングと機能追加に対応

## 主要な特徴

### ゲーム機能
- **26階層の手続き生成ダンジョン**: オリジナルRogueに準拠した階層構造
- **ターンベース戦闘システム**: 戦略性を重視した戦闘メカニクス
- **包括的なアイテムシステム**: 武器、防具、ポーション、巻物、食料、指輪、杖
- **ゴールドオートピックアップ**: 移動時の自動ゴールド回収システム（実装中）
- **アイテム識別システム**: 未識別アイテムの発見と識別メカニクス
- **魔法システム**: 杖による魔法効果の実装
- **状態異常システム**: 毒、麻痺、混乱などの実装（計画中）
- **トラップシステム**: 落とし穴、毒針、テレポートトラップ（計画中）
- **セーブ・ロード機能**: ゲーム状態の永続化

### 技術的特徴
- **Command Patternアーキテクチャ**: コマンドとハンドラーによる責務分離
- **モダンなGo開発**: Go 1.24、静的型付け、並行処理対応
- **ゲームライブラリ**: gruid（ゲーム開発フレームワーク）、gruid-sdl（SDL2バックエンド）
- **包括的な品質管理**: golangci-lint、go test、自動テストスイート
- **効率的なパッケージ管理**: Go Modules（標準依存関係管理）
- **統一コマンドインターフェース**: GUIとCLIの完全統合
- **JSONベースセーブシステム**: 構造化データの永続化

## アーキテクチャの特徴

### 設計原則
1. **Command Pattern**: コマンドベースのアクション処理
2. **責務分離**: 各構造体が単一責任を持つ
3. **マネージャーパターン**: 機能を管理クラスに分割
4. **Builder Pattern**: 複雑な生成処理を段階的に構築
5. **State Pattern**: ゲーム状態の明確な管理
6. **インターフェース指向**: 疎結合で拡張可能な設計

### 主要コンポーネント
- **Core**: ゲームエンジン、状態管理、入力処理
- **Game**: アクター（プレイヤー・モンスター）、アイテム、ダンジョン、魔法効果
- **UI**: スクリーンシステム、描画処理、ユーザーインターフェース
- **Config**: 設定管理、環境変数処理
