# GoRogue 機能一覧

## 現行スコープ

ゲーム要件と受け入れ条件は [`SPEC.md`](../SPEC.md) を正とします。GoRogue 0.3.0 は Rogue 5.4.4 の原典にあるゲーム機能を対象とし、過去の設計案や未実装の機能を要件として扱いません。

- 26 階のシード付きダンジョン生成。部屋、通路、暗室、宝物室、迷路階、隠し通路・隠し扉、階段、罠を含みます。
- Rogue の移動、戦闘、経験値、回復、空腹、モンスター行動、装備、アイテム効果、識別を実装します。
- Rogue のコマンドは GUI と CLI で共有する実行経路を使います。
- 罠の発見、発動、効果を実装します。原作にない罠解除操作はありません。
- 26 階でイェンダーのアミュレットを取得し、地上へ戻ると勝利します。HP が尽きるとパーマデスです。
- JSON セーブ形式は `1.4.0`。ゲーム進行に必要なプレイヤー、階層、モンスター、アイテム、識別、罠、乱数状態を保存します。旧形式の自動移行はしません。
- 表示層は論理表示セルを端末文字・色・gruid セルへ変換します。タイル画像やアニメーションは対象外です。

## 操作

| キー | 操作 |
| --- | --- |
| `h j k l y u b n` | 8 方向へ移動 |
| `H J K L Y U B N` | 8 方向へ走る |
| `.` | その場で休む |
| `f` | 方向を指定して戦う |
| `,` | アイテムを拾う |
| `d` | アイテムを落とす |
| `e` | 食べる |
| `w` / `W` | 武器を装備 / 防具を着る |
| `T` | 防具を脱ぐ |
| `P` / `R` | 指輪を装備 / 指輪を外す |
| `t` | アイテムを投げる |
| `q` / `r` / `z` | 薬を飲む / 巻物を読む / 杖を振る |
| `s` / `^` | 周囲を探す / 指定方向を調べる |
| `i` / `@` | 所持品 / キャラクター情報 |
| `D` / `c` | 発見済みアイテム / 未識別アイテムに名前を付ける |
| `<` / `>` | 上る / 下りる |
| `a` | 直前のコマンドを繰り返す |
| `Q` / `Escape` | 終了 / キャンセル |

GoRogue 固有の補助操作: `^W` でウィザードモード、`:` で CLI デバッグ入力に切り替えます。

GUI 固有のキー表記と名前付き CLI コマンドは `SPEC.md` を参照してください。原作キーの意味を別の意味で上書きしません。
