# UI コンポーネント

UI の実装は `internal/ui/screen/`、エントリーポイントは `cmd/gorogue/` と `cmd/gorogue-cli/` にあります。規範要件は [`../../SPEC.md`](../../SPEC.md) を参照してください。

- 画面は入力モードと表示を管理し、ゲーム規則は共有コマンド実行経路へ渡します。
- GUI と CLI は同じゲーム状態とコマンド executor を利用します。
- 論理表示セルは位置、論理地形、可視/探索状態、表示エンティティ、優先順位を表します。
- `TextRenderer` が表示記号、色、gruid グリッド/セルへ変換します。SDL2 は GUI の出力ドライバーです。
- 非可視の地形・エンティティを隠し、探索済み地形を記憶どおりに表示します。

魔法詠唱画面、MP UI、独自の罠解除画面、未実装のコンポーネントを現行機能として説明しません。入力一覧は [`../features.md`](../features.md) を参照してください。
