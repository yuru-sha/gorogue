# ダンジョンコンポーネント

ダンジョンの規範要件は [`../../SPEC.md`](../../SPEC.md) です。実装は `internal/game/dungeon/` にあります。

- `Level` は論理タイル、部屋、階層番号、モンスター、アイテム、罠、乱数状態を保持します。
- 生成器は Rogue 5.4.4 の部屋・通路・迷路規則と固定シード再現性を扱います。
- `Tile` は論理地形、可視状態、探索済み状態を保持し、文字や色は保持しません。
- 隠し通路・扉、暗室、宝物室、階段、トラップの配置・状態はゲーム層に属します。
- 階層マネージャーは移動後に各階層状態を復元します。

過去の BSP、確率的な別ダンジョン形式、画像タイルなどを現行仕様として扱いません。出典別の値や受け入れ条件は [`../../SPEC.md`](../../SPEC.md) を参照してください。
