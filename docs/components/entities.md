# ゲームドメインコンポーネント

このガイドは現行 Go パッケージの責務を示します。ゲーム要件は [`../../SPEC.md`](../../SPEC.md)、実挙動はソースとテストを正とします。

- `internal/game/actor/`: プレイヤー、モンスター、能力値、戦闘、進行に必要な状態。
- `internal/game/dungeon/`: 階層、部屋、論理タイル、視界、探索状態、生成、罠。
- `internal/game/item/`: Rogue アイテム種別、個数、装備・識別などのゲーム状態。
- `internal/game/magic/`: ポーション、巻物、杖などの原作アイテム効果。
- `internal/game/identification/`: 未識別アイテムの外観、識別、呼称。
- `internal/game/save/`: 保存データ、バージョン検証、復元。

ドメイン型は表示用グリフ、色、gruid `Grid`/`Cell` を持ちません。毒、幻覚など原作に存在する効果は原作仕様に従い、原作にない魔法詠唱や独自の逃走・状態システムを追加しません。個別のルールは [`../../SPEC.md`](../../SPEC.md) を参照してください。
