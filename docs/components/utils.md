# ユーティリティコンポーネント

`internal/utils/` にはログなどの共通実装があります。ログは `internal/utils/logger/` の `slog` ベース実装を利用し、`LOG_DIRECTORY` でログディレクトリを指定できます（既定値 `logs`）。ゲームログとエラーログを分けて出力し、設定されたログレベルとデバッグ設定を適用します。

設定値は `internal/config/` から取得します。ログ出力 API、ファイルローテーション、終了時のクリーンアップの実際の挙動は該当する Go ソースとテストを正とします。過去の Python/Tcod 構成や未実装のログ機能を現行設計として扱いません。
